# imapsync-web

Современная и удобная веб-панель для массовых и разовых миграций почты по протоколу IMAP. Движок переноса — **imapsync**, вокруг которого построена экосистема: автоматический импорт ящиков из CSV/XLS, валидация доступов до старта миграции, адаптивные счётчики, графики скорости в реальном времени, терминальный просмотрщик логов, автоматический догон дельты, сверка с целевым сервером (XLSX) и Telegram-уведомления.

---

## 🌟 Возможности панели

- **Удобный импорт**: Загрузка списка ящиков из CSV/Excel (поддержка `cp1251`, `utf-8`, разделителей `;` и `,`, авто-очистка хвостовых пробелов и дубликатов).
- **Валидация доступов до старта**: Проверка логинов/паролей на источнике и приёмнике до начала переезда — с защитой от блокировки учётных записей.
- **Интеллектуальное сопоставление папок**: Автоматическое приведение системных папок (`INBOX`, `Отправленные`, `Sent Items`, `[Gmail]/Sent Mail`, `Спам`, `Корзина`) с опорой на `SPECIAL-USE` и пресеты провайдеров.
- **Подсветка исключённых папок**: Явное указание в интерфейсе, если папка (например, *Спам* или *Корзина*) пропускается согласно настройкам проекта.
- **Высокая производительность `imapsync`**: Тонкая настройка сокетов (`--nocheckfoldersexist`, `--timeout1 300`), исключающая зависание больших ящиков (20+ ГБ) на Exchange и Mail.ru.
- **Живой мониторинг и логи**: Текстовые логи переноса в режиме реального времени, встроенный консольный просмотрщик и скачивание единого ZIP-архива со всеми логами проекта.
- **Сверка и XLSX-отчёты**: Опрос приёмника после миграции с генерацией детализированного отчёта о доставке сообщений по каждой папке.
- **Telegram & Webhook уведомления**: Оповещения администратора о завершении миграции проекта или критических ошибках.
- **Премиальный интерфейс**: Тёмная и светлая темы (без `TailwindCSS`, чистый CSS, переключение без Flash-эффекта), HTMX-поиск и пагинация, модальные окна и адаптивный дизайн.

## 🚀 Зачем панель, если есть imapsync?

`imapsync` — отличный консольный утилитарный инструмент для переноса одного ящика. Однако при миграции сотен ящиков возникают проблемы:

1. **Битые данные**: Таблицы со списками пользователей приходят в разной кодировке, с невидимыми пробелами в паролях и дублями.
2. **Ошибки авторизации**: Узнать о неверном пароле хочется до старта трехсуточного переноса, а не в его процессе.
3. **Контроль и прозрачность**: Необходимость видеть точную скорость (МБ/с), текущую папку и прогресс без зависших терминалов.
4. **Повторные прогоны**: Доперенос («досинхронить») дельты перед переключением MX-записей без повторного вычитывания всего ящика.
5. **Итоговый отчёт**: Заказчику/руководству нужен документ (Excel), подтверждающий, что письма физически долетели на целевой сервер.

`imapsync-web` берёт на себя всю рутину, оставляя `imapsync` задачу непосредственной прокачки сообщений.

## 🛡️ Безопасность

- **Шифрование паролей**: Пароли почтовых ящиков шифруются алгоритмом **Fernet** (AES-128 в режиме CBC с HMAC). Ключ задаётся в переменной окружения `FERNET_KEY` и не хранится в базе данных.
- **Защита процессов `ps`**: Учётные данные не передаются через аргументы командной строки `imapsync` — пароли передаются во временных защищённых файлах.
- **Разграничение прав**: Защита от брутфорса, роли пользователей (Admin / Viewer), журнал аудита действий.
- **Авто-очистка кредов**: Пароли ящиков автоматически стираются через 30 дней после завершения проекта или вручную в один клик.

## ⚙️ Установка и запуск

Готовый образ автоматически собирается в GitHub Container Registry (`ghcr.io`):

```bash
git clone https://github.com/Ttolyanich/imapsync-web.git
cd imapsync-web
cp .env.example .env
```

Сгенерируйте `FERNET_KEY` и задайте `ADMIN_PASSWORD` в `.env`:

```bash
docker run --rm ghcr.io/ttolyanich/imapsync-web:latest python3 -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

Запустите контейнеры через Docker Compose:

```bash
docker compose up -d
```

Панель станет доступна по адресу `http://127.0.0.1:8090`.

### Обновление до последней версии:

```bash
docker compose pull && docker compose up -d
```

## 📁 Пресеты почтовых серверов

В папке [`presets/`](presets/) содержатся описания почтовых систем в формате YAML:
- **Mail.ru**
- **Яндекс 360**
- **Gmail / Google Workspace**
- **Exchange (On-Premise / Hosted)**
- **Zimbra**
- **Generic IMAP** (Кастомные IMAP-серверы)

Пресеты содержат оптимальные параметры подключения, лимиты параллельности и правила сопоставления папок. Для добавления нового провайдера достаточно создать один YAML-файл.

## 🛠️ Разработка и тестирование

### Локальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate  # на Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
alembic upgrade head
flask --app app.wsgi run --debug
```

### Запуск модульных тестов:

```bash
python tests/test_units.py
```

### HTTP Smoke-тесты:

```bash
SMOKE_PASSWORD=пароль_админа python tests/smoke_http.py
```
